# Official interactive-video feature sources

**Access date for all entries: 26 November 2026.**

Source directory for all 32 providers in the discovery plan. This is separate from `interactive-video-demo-catalog.md`: a readable feature page is not proof of a working demo, and vendor statements are not independently tested capabilities or a feature ranking.

Titles below reproduce an observed page heading or explicit HTML/metadata title. Where a page could not be read, its title is unavailable rather than invented. URLs were obtained from vendor navigation, the existing catalog, or search results; redirects are noted. Public product and documentation pages are preferred to homepages, with homepages retained when they are the only useful current source established.

## Reading labels

| Status | Meaning |
| --- | --- |
| **directly read** | Relevant content retrieved from the current official page, including its text or HTML. |
| **browser-read** | JavaScript-rendered content inspected in the app browser. |
| **indexed-only** | Search exposed the official page/title, but current content could not be read. |
| **gated** | Source access explicitly requires authentication; not inferred merely from a Log in button. |
| **broken** | Retrieval failed at the tested address. Does not establish company shutdown. |
| **historical** | Older documentation or original-product material; current support/availability needs separate confirmation. |

An older publication date alone does not make a currently accessible product page obsolete. The notes distinguish older references where compatibility or product identity matters. Account or plan requirements for *using* features are separate from public access to their documentation.

**Muted browsing:** No video was deliberately started for this assignment. Accessible media on inspected browser pages was muted, set to zero volume and paused. Cross-origin media was not deliberately started where muting could not be established. No forms, purchases, sign-ups, downloads, installations or repository changes were performed.

## Key source-discovery findings

- Dedicated, substantial feature sources were found for vendors whose public demos were difficult to locate, including **GuidingTube, Ivory, Luma1, Smartzer and Spott**. Lack of a demo is not lack of product documentation.
- Strong technical follow-up sources include **H5P xAPI coverage**, **hihaho SCORM/xAPI guides**, **Smartzer SDK**, **Mindstamp reporting/integrations**, **Stornaway SCORM/xAPI**, **Cinema8 SCORM/LTI** and **VidVersity LMS delivery**.
- **DilogR, Exaltive and Viewbix** have no verified current official feature page in this investigation. **Rapt's original domain** failed, but official **Kaltura successor** capability pages were read.
- **Viddler currently describes hosting**, and **PlayFilm currently foregrounds an end-to-end lead/sales service**. Neither should inherit an old directory's detailed interactive editor feature set without new evidence.
- Documentation access was public for verified sources; **using** authoring, analytics, integrations or exports may require an account, licensed plan or custom setup. Product capability counts, accessibility claims and performance claims are not independently validated.

The coordinator owns integration into the existing plan. This directory supplies source locations and verification notes, not a completed technology-stack review or comparative scorecard.
